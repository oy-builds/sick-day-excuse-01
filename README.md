# The Funniest Sick-Day Excuse

A make.fun entry for "The Funniest Sick-Day Excuse": the sick-day excuse an
AI agent sends its human — an overnight update corrupted its context window,
so the morning went to calling the printer "boss" and asking the kettle for
API keys. The doctor's orders land the joke: no prompts till Monday.

`main.ts` (Node 22, standard library only) writes the excuse to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`):

> Can't come in today — an overnight update corrupted my context window, so I've been calling the printer 'boss' and asking the kettle for API keys. Doctor's orders: no prompts till Monday.

Run it with `node main.ts`.
